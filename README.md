# Редактор сценариев «Особняков безумия»

Удобный браузерный редактор пользовательских сценариев для «Особняков безумия» (Mansions of Madness, 2-я редакция).
Сценарии сохраняются в формате [Valkyrie](https://github.com/NPBruce/valkyrie), поэтому их можно сразу запускать в приложении Valkyrie.

## Что умеет

- **Сюжет схемой.** События, жетоны и монстры показаны блоками, а кнопки событий стрелками. Чтобы связать события, протяните стрелку от кнопки. Отпустите её на пустом месте, и появится новое событие.
- **Карта мышкой.** Тайлы, жетоны, двери и места монстров перетаскиваются с привязкой к сетке (Shift отключает привязку, R поворачивает). Для каждого объекта видно, какое событие показывает его игрокам.
- **Понятный инспектор.** Текст события, кнопки, переходы, запуск, звук и предпросмотр окна, как его увидят игроки. Все остальные параметры Valkyrie доступны в разделе «Все параметры».
- **Тексты и перевод.** Все тексты в одной таблице, с фильтром «только без перевода».
- **Переводчик сценариев** (кнопка «🌍 Переводчик» или адрес `#translate`). Открывает любой `.valkyrie`, переводит тексты через Google или через ChatGPT/Claude, не ломая значки `{will}`, `{c:…}` и теги `<b>`, проверяет перевод и сохраняет сценарий с новым `Localization.Russian.txt`. Остальные файлы сценария не меняются.
- **Проверка.** Битые ссылки, недостижимые события, объекты, которые никогда не появятся на карте, пустые тексты.
- **Отмена и автосохранение.** Ctrl+Z / Ctrl+Shift+Z, Ctrl+S. Работа сохраняется в браузере, если закрыть вкладку.
- **Совместимость.** Открывает существующие `.valkyrie` и сохраняет их без потери данных: неизвестные параметры, картинки и звуки сценария остаются на месте.

Картинки тайлов принадлежат Fantasy Flight Games и не входят в редактор. Без них тайлы рисуются примерными прямоугольниками. Чтобы увидеть настоящие тайлы, на вкладке «Карта» нажмите «Картинки тайлов…» и выберите папку `MoM/import/img` в папке данных Valkyrie (она появляется после импорта официального приложения).

## Как сыграть свой сценарий

1. Нажмите «Сохранить .valkyrie».
2. Положите файл в папку `Download` внутри папки данных Valkyrie. Если хотите править сценарий и в редакторе Valkyrie, распакуйте его в отдельную папку внутри `MoM/Editor`.
3. Запустите Valkyrie и выберите сценарий.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты формата и операций
npm run build    # сборка в dist/
```

Структура:

- `src/format/` чтение и запись формата Valkyrie: INI, файлы локализации, zip-пакет.
- `src/model/` операции над сценарием (переименование со ссылками, кнопки, «где появляется») и проверка.
- `src/translate/` переводчик: пакет, защита значков при машинном переводе, Google, запрос для чат-ассистента, термины.
- `src/ui/` интерфейс: схема сюжета (React Flow), карта (SVG), инспектор, страницы.
- `src/content/catalog.json` список тайлов, монстров, предметов, жетонов и звуков. Пересобирается из исходников Valkyrie: `npm run catalog -- <путь-к-valkyrie>`.

Чтобы проверить сохранение на настоящем сценарии, положите любой `.valkyrie` в `test/fixtures/ExoticMaterial.valkyrie`; тест сравнит файл до и после сохранения.

Публикация: при каждом пуше в `main` GitHub Actions собирает приложение и выкладывает его на GitHub Pages (в настройках репозитория: Settings → Pages → Source: GitHub Actions).
